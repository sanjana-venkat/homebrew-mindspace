# Homebrew tap for Mindspace

    brew tap sanjana-venkat/mindspace
    brew trust sanjana-venkat/mindspace
    brew install --cask mindspace

Homebrew 6 will not load a cask from a personal tap until you trust it — that is
the middle line, asked once. The app itself is signed with a Developer ID and
notarized, so macOS opens it without complaint.

Source: https://github.com/sanjana-venkat/mindspace
